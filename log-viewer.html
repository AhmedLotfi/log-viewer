Help & usage

Loading logs

  • Click Load Log Files to pick one or more .txt / .log files.
  • Drag and drop files anywhere on the page.
  • Tail picks one file and re-reads it every 2 s; the page offers to resume after a refresh.
  • Single files larger than 10 MB are streamed in chunks instead of loaded as one string.
  • Both Serilog bracketed text and JSON-line (CLEF / generic) formats are detected automatically.

Searching & filtering

  • Type in the search box to filter by message + exception text. Matches are highlighted in the table.
  • The three small buttons after the search field toggle case-sensitive (Aa), whole-word (W), and regex (.*) modes. The box turns red on an invalid regex.
  • Click the level pills (DBG, INF, WRN, ERR) to toggle each level off and on.
  • Use From / To to bound the date range. Date-only entries are normalized to start/end of day.
  • Active filters show as removable chips just above the table. Reset filters clears all of them at once.

Inspecting an entry

  • Click ▸ on any row to expand it inline — full message, exception, correlation, source.
  • Click anywhere else on the row to open the detail modal with a Show trace button (filters to all logs sharing the same correlation).
  • Collapse repeats groups adjacent identical messages into one row with a ×N badge.

Reports

  • Open Reports for log distribution, API performance, internal HTTP, exceptions, and activity.
  • Most rows are clickable — they cross-link to a filtered view of the matching log entries.
  • The ▸ on each exception row reveals all reasons + APIs that produced that type/reason.
  • Hour bars in the Activity timeline are clickable — they filter to that hour-of-day across all dates.
  • Loading two or more files shows a Files compared table with side-by-side metrics per file.

Saved views & sharing

  • Views → Save current view… stores the current search, level filters, dates, hour, sort, and collapse toggle under a name (in localStorage).
  • Filter state is also serialized to the URL hash, so reloading or copying the URL preserves the view.
  • Export downloads the currently-filtered logs as plain text. Export Report dumps the full analytics as JSON.
